# M3-P0-B — Q02/Q03 报价状态与目录返回一致性

日期：2026-10-31。基线：`main@789c4c58bcf37aba844a7a43a96c81fcd0030538`（M2-B）。

## 范围与问题

- **已恢复套餐编辑**：工作台已经持有已配置的套餐，但新会话尚未读取套餐目录。原“编辑配置”直接发起详情查询，与异步首屏目录加载竞态，可能出现“套餐不属于当前已读取的目录结果”。
- **离开目录后迟到的详情**：切类别、返回工作台、从详情退回列表时，已有套餐详情请求未统一失效；旧响应可能在后来更新浏览器状态。
- **误导性文案**：新套餐尚未点击“加入当前维修部位组”前，详情却写着“配置已加入”。

## 本批修正

1. 已保存套餐重新编辑时，先等待当前工单的套餐列表读取完成，然后在**相同目标维修部位组和仍打开的目录会话**内按目录候选身份读取详情。返回或切换期间迟到的导航不再继续。
2. 套餐详情的打开、关闭、切类别和返回列表统一取消旧请求结果；不会因迟到的详情回填造成旧 UI 复现。
3. 套餐不在**已加载**目录页时明确提示继续加载再编辑；不自动请求所有目录页，也不接受没有已验证列表身份的套餐。原草稿保持不变。
4. 初次配置与编辑已有配置采用不同的真实状态文案。正式提交、订单和签约权限均未改变。

# CUI-02｜报价组件 CSS 样式归属和重复声明治理

**日期**：2026-10-28 · **基线**：CUI-01 Draft #226 HEAD `ac970601` · **工作 PR**：#227。

## 问题与证据

Q03 四 Tab 上下错位的根源，是普通按钮没有明确垂直居中，加上多代 CSS 同名选择器叠加。CUI-01 删除了 169 条无 DOM 所有者的样式，把旧报价主文件由 118,851B 降到 98,024B，仍检测到 **185 个重复定义的选择器**。直接清空会破坏套餐、SKU、业务状态、已认可的 Q01/Q03 视觉。

## 一次性组件拆分

| 样式所有者 | 文件 | 职责 |
|---|---|---|
| 公共语义 | `QuotationActionContent.styles.css` | 页面骨架、通用反馈/状态、跨模块共享规则 |
| 首步/编辑 | `QuotationEditor.styles.css` | 报价首步与空状态；新 `Q01EntryScreen` 保持自己的 SFC 样式 |
| 分组明细 | `QuotationGroups.styles.css` | 维修部位、报价组成、项目明细与数量 |
| 套餐配置 | `QuotationPackageConfiguration.styles.css` | 套餐展开、材料层级、SKU 选择和确认 |
| 目录/选品 | `QuotationCatalog.styles.css` | 分类 Tab、搜索、商品卡、单价、已选反馈和底栏 |
| 已批准的最终视觉 | `Q01CommercialBaseline.css` / `Q03CommercialBaseline.css` | 已接受的视觉标准，始终最后加载 |

**禁止**在新页面再叠加临时 override 文件。调整控件应从真实 DOM 所有者修改，再检查实际几何和截图。

## 代码治理过程及量化结果

1. 保留原 CSS 的各业务分支样式，按选择器责任域迁移到五个所有者；每个所有者内部的规则顺序保持可追踪。没有删除任何业务方法、数据模型或接口。
2. 删除 **126 条被随后同一选择器及属性无条件覆盖的规则**（保留 `!important` 优先级，不将有状态的其他选择器误判为失效）。
3. 进一步合并 **247 个同一所有者内的重复规则块**：将同名选择器的声明依既有先后次序组合，不改变最终声明值；最后以真实截图像素对照验证未引入视觉漂移。
4. 组件样式总体积：**98,024B → 73,258B（−25.3%）**。相对于 CUI-01 之前 118,851B 为 **−38.4%**；单一旧 CSS 的 185 个重复选择器已收敛为**五个所有者之间、内部均无重复根选择器**（同名 `@media` 不属于组件选择器）。
5. 保留老样式中的六个 `max-width:360px` 响应规则于公共层；本批 Owner 审核只要求固定 375px，不将其作为设备兼容验收通过的证明。

## CI 约束

`scripts/ci/quotation-css-owners.mjs` 与独立 `CUI-02 Quotation CSS Owners` 工作流保障：
- 每个选择器恰有一个组件 CSS 所有者，不允许在两个 Owner 文件重复定义；
- 所有五个文件在实际 Vue SFC 中各被引入一次；Q01/Q03 视觉基准始终在其后；
- 不允许用重写旧版 CSS 的方式把总体积涨回 76KB 以上；
- 不改变现有 CUI-01 禁止的废弃目录规则。

实际 App 视觉等价依据：相同 375×667 DEV Mock 场景 Q01 五张 PNG、Q03 三张 PNG，与 CUI-01 净化后基准逐像素比较；覆盖首页/工单详情/Q01 首步/Q03 热区的跨页几何门禁持续执行。测试结果均必须绑定精确提交 SHA，不能套用前一个 HEAD 的 CI。

## JSON replacement and recovery

Only changed authorized scalars enter the patch. The existing full-original wire carries unknown root/EXTS/readonly/hidden values and independent FormData/list titles without replacing them with node labels. Effective EXTS own keys take precedence. Optional clear requires proven original root and EXTS slots; both are deleted and conditions are evaluated against actual persisted absence. Unchanged hidden empty slots are restored before condition evaluation; an independent initial+patch-minus-clears state check prevents hidden writes. Required/invalid input and no-op edits fail before dispatch. No arrays are newly emitted. Save is upsert → verified complete EXTS update → exact ID/JSON readback, never automatic Process.

Predispatch failure can recover only after an explicit fresh authorized read. Unknown ACK, postdispatch drift or inconsistent readback remains uncertain across reread/reload and cannot auto-replay. A new read never turns an ACK into record edit permission.

- 将记录事务面板的非媒体样式迁入两个构建选择的 `node-records.scss`；修链原样式逐字节一致。媒体样式仍在原组件，逐字节一致，没有修改上传能力、媒体字段或协议。
- 雨虹使用 v2 token，16px 内边距、18/16/14px 信息层次、4/8px 控件/卡片、评审红 #C8202B。重复面板标题由皮肤隐藏，保留宿主实际节点名称。
- 复用 `_workspace-controls.scss` 同一套选择控件规则扩展到记录字段，不修改云端独占 `_primitives.scss`，不叠加另一套共享控件样式。
- 使用构建时 `node-record-profile.ts` 决定返回按钮层级：雨虹次级，修链保留原主按钮。雨虹确认操作期间隐藏额外保存行，保留一个突出的确认动作；不改变可执行操作或协议。
- 记录宿主补 `h5-navigation-fit`，修复 H5 页头占高导致底栏被挤出视口的实际缺陷。断言底栏底边≤932px，触区≥44px。
- 本机写入/读取明确失败使用雨虹错误色；清理失败及结果待核对不冒充记录未保存或节点成功。

未改 quotation、signing、附件/媒体组件及样式、R1NodeFormsReadPanel、治理脚本；没有创建新架构、依赖或本机项目副本。

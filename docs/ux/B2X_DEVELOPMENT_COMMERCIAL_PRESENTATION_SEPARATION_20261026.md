# B2-X｜开发验收与商业信息分层（2026-10-26）

**状态：已实施展示层改造，待浏览器/微信开发者工具视觉复验与 Owner 审核。**

上游基线：B1 PR #219 + B2 PR #220。B2-X 只触及用户可见文案、展示条件、DEV 入口及其测试，不改变读写适配器、DTO、订单状态、Workflow 权限、价格计算或模拟回执。

## 1. 原则：商业模式是默认值

1. **L1 业务内容（默认展示）**：客户、工单、当前任务、预约、勘察、报价、金额、材料、合同状态、可用主操作。
2. **L2 必要事实与安全边界（默认但低强调）**：`体验数据 · 未提交后台`、仅本机保存、只读/权限不足、价格待核实、合同不代表真实签约、结果未知不可重发。不可移除或美化成真实成功。
3. **L3 开发验收信息（默认不渲染）**：Mock 数据源开关、场景编号、草稿诊断、工作流仿真轨迹、SKU 身份对照、原始合成 ID、签约 API/Handler/命令契约审查。只在主动开启的 DEV 核验模式出现。

生产与 Beta **不能**因带上一个页面参数解锁 L3：构建时 `import.meta.env.DEV` 是强制前提。此开关只影响可见性，不参与数据源选择、鉴权、写入或网络许可。

## 2. DEV 验收模式与恢复

| 模式 | 进入方式 | 屏幕行为 | 生命周期 |
| --- | --- | --- | --- |
| 商业观感（默认） | 正常进入首页 | 隐藏所有 L3；Mock 数据仍有 L2 提示 | 新浏览器标签默认如此 |
| 开发核验 | DEV 环境打开 `/#/pages/index/index?devReview=1` | 开启首页 Mock/场景/草稿诊断；在业务页面显示 L3 细节 | 当前 H5 标签内会话保留；小程序同一运行实例保留 |
| 返回商业观感 | DEV 环境打开 `/#/pages/index/index?devReview=0` | 立即隐藏 L3，不删除任何草稿或改动 Mock/Real 模式 | 当前标签会话取消；刷新后仍保持商业观感 |

H5 仅使用 `sessionStorage` 记录显式模式选择，不用持久业务存储。无 `window` 时只使用进程内响应式状态。失去浏览器存储权限时按内存状态运行。没有隐藏触发手势，也没有面向普通用户的“调试开关”。

**在 Mac 微信开发者工具**：开发工具启动 DEV Mock 后使用首页带 `devReview=1` 的页面参数/启动场景开启验收；完成检查后以 `devReview=0` 返回商业界面。具体启动页面参数以工具和实际构建为准，不用 Production 账号验证。

## 3. 统一改造范围

| 主屏/组件 | 默认商业模式 | opt-in DEV 核验 |
| --- | --- | --- |
| 首页 | 任务与工单入口；独立低强调体验数据来源 | 数据源切换、MOCK 场景入口、草稿元数据和生成/清理工具 |
| 工单详情 | 客户、任务、步骤、表单；合成工单显示简洁编号及来源 | `MOCK-*` 原编号、Mock 流程轨迹、进度核对及子流程测试入口 |
| 预约/勘察 Action | 可操作表单、下一步、前序字段摘要；本机状态真实披露 | 场景链路上下文由 DEV 跨页 QA 抽检；保留操作与回读能力 |
| Q00 订单中心 | 已有订单/草稿、金额、分组、下一步；本机报价记录与正式只读明确不同 | 订单原始 ID 和 Mock 商业验收快捷入口 |
| Q01 报价编辑 | 维修部位、数量、材料/施工、价格；本机草稿核对 | SKU 来源/身份/关联/销售属性模拟审计 |
| 报价本机回读 | 金额示例、创建本机记录、未知结果可核对、未提交后台 | R1 模拟子流程与回执核验说明 |
| 特殊多表单/重复表单 | 本机新增、编辑、删除、完成；真实失败保护 | 详细 Mock 凭据说明保留在开发模式 |
| C01 签约只读 | 当前签约进度、合同示例、关闭的签约操作；合成 ID 不外显 | 原始合成订单/合同身份、处理人、接口路径和命令条件预检 |
| 独立 SKU/签约/子流程 Mock 审查页 | 常规导航不可达 | 仅从 DEV 核验入口访问，保留技术准确性与断言 |

`data-testid` 保留以便测试读取已存在的业务信息。Mock 数据不得自动“冒充” Production 订单；只读/业务写入禁用控制不由 CSS 或上述开关控制。

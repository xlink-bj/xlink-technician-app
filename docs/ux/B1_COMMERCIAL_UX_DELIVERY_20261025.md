## 1. 这次集中改造的规则

1. 一次只把一个「下一步主任务」做成主按钮；查看详情、重新读取和签约状态查看属于次级动作。
2. 状态分四层：**本机草稿 → 本机合成回读 → 已核验正式订单（仅只读）→ 已确认合同状态**。任何一层均不能推断下一层已经完成。
3. 技术员先看**当前阶段、当前维修部位和下一步**，再看辅助说明、异常信息与内部诊断；有风险的动作保持清楚的权限提示。
4. 登录、工单详情任务焦点、预约、勘察 S01–S05 及 Q00/Q01/Q03 已认可设计方向不重新设计；只在确有事实缺陷处改动。
5. 375×667 为必审单一视口。本轮不把 390×844、实体设备适配、Beta 写入或 Owner 商业化审美签字并作 B1 代码阻塞。

## 3. 不能因为 B1 视觉改动而发生的事

- 从“本机保存”显示成“正式订单创建成功”“服务器已核对”“已签约”。
- 依据合同列表为空断言合同不存在，或依据订单列表的前三条断言全量为空。
- 在 Dev 合成订单里提供真实签约页面入口或调用任何签署/短信/创建 PDF 接口。
- 自动重发一个结果不明的 Mock 保存或完成请求；不能跳过角色、工单和具体 Order 核验。
- 修改已批准的 S01–S05 字段契约、部位多选/级联规则、金额真值或提交资格。

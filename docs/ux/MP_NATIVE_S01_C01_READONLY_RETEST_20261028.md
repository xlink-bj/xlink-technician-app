# MP 375px 原生补验：S01 → Q00/Q01/Q02 → C01（隔离合成数据）

状态：**待 Mac 微信开发者工具取证**。本文件是验收步骤，不是已通过的原生报告。

## 范围与严禁事项

- 仅使用本地 `DEV` Mock + 合成角色 `synthetic-user / synthetic-role`；业务 API 固定 `https://example.invalid`，禁止 Production/Beta 业务请求、提交、签约、短信或部署。
- S01 的 `MOCK-019` 预约→勘查→报价只通过 Mock FormData/Process 读回协议转移；UI 仍为本地草稿预览，不能升级成真实流程执行权限。
- **C01 使用独立 `04009` 的已核验合成正式订单只读样本**。`019` 本地报价草稿不能生成正式订单；不能把独立签约 Mock 展示页或伪造 OrderId 当成商业 C01 通过证据。
- 微信开发者工具模拟器通过只能记为 `MP_SIMULATOR_PASS`，不能声称已经过真机触控/键盘验收。

## 安全启动

1. 在 Mac 主仓库确认检出的 SHA、分支、无未提交业务代码。使用 Node 22、pnpm 10。
2. 执行 `pnpm run dev:mp-weixin:mock-ux`。该命令固定本地隔离环境；不要复制真实 API、授权 token 或 `.env` 到 Mock 启动环境。**这是 DEV watch 编译**，`pnpm run build:mp-weixin` 为发布型构建，无法用于开启 DEV 夹具。
3. 微信开发者工具导入 `dist/dev/mp-weixin`（以实际 UniApp CLI 输出路径为准），设置 **iPhone 6/7/8，375×667**，检查基础库版本。若已有缓存 Mock 状态，在 QA 控制台手动切回“完整数据”；不得通过改动守卫强行进入页面。
4. 从 DEV 主页的 `devReview=1` 进入“开发 QA 控制台”，看到 `Mock` 数据来源。检查 console、network 中没有业务域名请求；任何真实网络调用即本轮终止并标记 FAIL。

## 用例 A：连续 S01 只读预览

1. QA 控制台选“连续业务旅程 · MOCK-019”。若之前已走到后续阶段，**记录当前阶段**；不能在未记录证据的情况下清空模拟器所有 storage 伪装首次通过。
2. 当前为预约阶段时，在预约表单填写可辨识的合成备注，如“MP375勘查回读”，等待“已保存，可继续下一步”；点击“继续现场勘察”。这一步仅是 Mock 协议转移，不应出现真实提交成功语义。
3. 返回 `#26019` 工单详情，当前任务应显示“现场勘察”；从该工单主任务入口进入 S01，**不要走独立 Mock 场景**。检查预约备注在“前序现场记录”可回读。
4. 在 S01 选择维修部位（确认后生效），输入可辨识的面积 `14.5`，等本地草稿保存。不要点击真实业务“完成勘查”；使用 DEV 限定“继续填写报价”。
5. 回到 `#26019` 工单详情，任务为报价。从主任务进入 Q00，再进入 Q01；展开“前序现场记录”，核验预约备注、勘查部位和 `14.5`。收起后检查商业内容排版，Q02 可达，正式提交禁用。
6. 退出/重进一次，确认前序记录和本地草稿恢复，未出现跨工单数据；以 `#26018` 反证它不携带 `019` 的预约/勘查内容。

验收：主 App 路径可达、身份与节点一致、草稿能恢复、未确认的选择不落盘、无真实业务写入或 JavaScript 异常。若阶段跳转被正常的安全守卫阻断，记录准确节点、提示、控制台与存储状态，结果为 `BLOCKED_FIXTURE`，**不能放宽守卫来拿通过截图**。

## 用例 B：商业 C01 只读与越权反证

1. 返回工单列表，搜索 `04009`，打开合成陈女士工单，从主任务进入 Q00。
2. 找到已核验的 `mock-official-order-001` 订单记录，点击“签约进度”入口；必须进入 `/pages/work-orders/signing-order-read`，而不是 `/pages/work-orders/signing-mock-review`。
3. 看到 `signing-order-read-verified`、展示编号 `BJ202610260001` 和“全程只读”。展开“合同操作”，确认“查看合同”“发起签署”禁用；如合同状态核验按钮出现，只允许既有只读 Mock 请求。
4. 用独立负例验证伪造的 `workOrderId=mock-work-order-019-continuous-journey&orderId=forged-order` 被拒绝、没有“已核验”显示；此负例不能代替正常商业路径。

验收：只能在已核验 Order 的归属范围内打开商业 C01；019 草稿不能冒充订单；只读展示不代表合同已签署。若 `04009` 在原生环境不可达，记录具体断点，仍为 `BLOCKED_FIXTURE`。

**验收视口：** 微信原生与 Main H5 均以 375×667 为首次可比基线。

## 1. 商业化不是换皮：体验质量的五个可观察目标

| 目标 | 一线场景中的定义 | B2 可验证标准 |
| --- | --- | --- |
| 任务优先 | 打开页面先知道**做什么**，无需阅读工程说明 | 375×667 首屏有当前任务及一项明确下一步，辅助信息不抢占主视线 |
| 信息克制 | 信息按当下行动价值排布，不要求人员理解开发词汇 | 常态只呈现业务结果/金额/客户/部位；溯源、调试、历史详情可以按需展开 |
| 状态可信 | 草稿、合成回读、正式只读、签约进度不可混用 | 任何金额/成功提示有明确来源；未知或有限读取不显示成肯定结论 |
| 操作稳定 | 户外单手操作，不依赖精细点按 | 关键可触达区域不小于 44px；保存、返回、失败恢复与禁用含义一致 |
| 视觉统一 | 同一业务含义在多个页面看起来一样 | 色彩、字级、容器、CTA、反馈由既有共享语义 Token/组件主导，不产生并行设计系统 |

**体验一句话：** 最先告诉技术员“我在哪里、做什么、下一步按哪里”，仅在需要时展示“为什么不能操作、证据从哪里来”。不能通过隐藏真实安全限制换取简洁。

## 2. 五类可复用屏幕原型（Archetypes）

| 原型 | 适用页面 | 首屏信息顺序 | 固定交互规则 |
| --- | --- | --- | --- |
| A. 今日任务型 | 首页、工单详情、预约 | 工单对象 → 当前任务 → 主行动 → 次级信息 | 任务焦点比统计数字优先；已获认可页面冻结 |
| B. 现场采集型 | 勘察、动态表单、特殊节点 | 当前节点 → 现场字段 → 媒体/测量 → 保存/完成 | FormDef 决定显隐和必填；保存不等于节点完成；错误就地解释 |
| C. 商业记录型 | 报价订单 Q00、历史/列表 | 当前工单 → 记录/金额/状态 → 查看详情 → 新建/继续 | 列表卡默认概览；辅助金额/更新时间按需展开；一个底部主 CTA |
| D. 分步配置型 | 报价 Q01、目录 Q03、SKU | 当前维修部位 → 第几步/已选数 → 当步字段/目录 → 继续/返回 | 分组归属永远可见，离开目录不丢所选，不暗示创建正式订单 |
| E. 核验结果型 | 合同/签约 C01、回读、错误恢复 | 当前状态 → 下一步 → 许可操作 → 订单证据 → 技术详证 | **先状态与行动再详证**；只读不得出现可用的签署动作；查询有限则结论有限 |

不重画已通过的登录、首页/列表/详情核心信息架构、预约与 S01–S05 已批准的控件结构。共享规则只在具体组件确有差异时渐进接入。

## 3. 统一视觉与交互合约

1. **排版**：业务标题 18–20px；主要动作 15–16px；目录项目 15px；说明正文 13–14px；真实次级说明不低于 12px。11px 以下不得用于任务状态或操作结果。
2. **颜色**：白底/浅灰页面；蓝色用于可行动与当前步；绿色只用于已证实的积极状态；警告只用于风险或必要限制。不以绿色装饰未核实的 Mock 成功态。
3. **卡片**：一张业务卡表达一个概念，减少卡套卡。只有金额、状态、当前部位进入默认展开区域；来源/历史明细转二级。
4. **CTA**：屏幕上只有一个主动作。保存草稿与正式提交不可共用按钮文案；真实签约/短信/PDF 的禁用理由必须可见。
5. **进度**：步骤条依据既有已证实的只读模型或本机表单步骤，不从点击动作推断服务器成功。
6. **状态与告知**：显示“本机草稿/未提交后台”“本次只读已核验”“本次未查到”“结果待核对”；只有真实后端回读授权才可显示正式成功。
7. **平台适配**：使用 WXSS 兼容选择器；不引入网页特有弹层替代原生控件，不覆盖既有触控语义、横向滚动和安全底部区域。

共享语义变量在 `src/shared/ui/design-system.scss` 的 `--app-journey-*` 命名空间；继承已有 `--app-craft-*` 视觉主权，**不创建第二套独立主题**。页面只定义业务排序与容器布局。

## 4. 四条 Golden Experience 主线

| 主线 | 起点 → 用户目标 | 成功路径 | 必需否定路径 |
| --- | --- | --- | --- |
| G1 预约 | 工单详情 → 电话沟通后确认预约 | 可见当前任务→时间/上门选择→保存→本机回读 | 无需上门、时间错误、只读、离开恢复 |
| G2 勘察 | 当前节点 → 维修部位及现场证据完整 | 选择部位→测量→原因→媒体→保存→完成确认 | 必填缺失、媒体失败、动态不支持、角色只读、回读异常 |
| G3 报价 | 当前工单 → 可解释的报价草稿 | Q00→Q01→Q03 套餐/工序/材料/SKU→返回同组→金额预览→本机草稿重启 | 无 SKU、价格未知、有限订单读取失败、重复/结果未知、正式提交关闭 |
| G4 签约 | 已核验的 Order → 理解合同目前进度 | 当前状态→仅 DEV 的合同只读核验→合同记录→下一步/返回 | 合同查询空非不存在、合同失败、签署/短信/PDF 禁用、Mock≠正式 Order |
